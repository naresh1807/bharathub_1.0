BUG THIS FIXES: messaging/candidate_messages.html used to hand-roll its own 2-item topnav (Dashboard, Messages only) instead of the real navigation -- so clicking "Messages" made every other nav item (Profile, Videos, Job Matches, My Applications, Logout, ...) disappear, because that page never rendered them in the first place. SAME BUG, FOUND AGAIN: jobs/job_browse.html and jobs/my_applications.html had an identical problem -- they used their own stripped-down jobs/_candidate_topbar.html (only Dashboard / Job Matches / My Applications, no sidebar at all), so clicking "Job Matches" or "Job Applied Status" made Profile, Videos, Chat, Mail and Logout disappear on those pages too. Both now include this same partial instead. HOW TO USE: {% include "candidates/_nav.html" with active="messages" %} Two kinds of nav items, same convention as employers/_nav.html: - Home / Profile / Videos / Mail still live TOGETHER as JS show/hide tabs inside candidate_dashboard.html, so their buttons call showSection(...) via onclick when you're already on that page. From any OTHER page (like this messages page), they fall back to a plain link back to the dashboard with ?section=... so the right tab opens automatically once there (candidate_dashboard.js reads that query param on load). - Job Matches / My Applications / Messages are real, separate pages, so those are always plain links. `active` tells this partial which single item to highlight. Recognised values: home, profile, videos, mail, messages, browse (Job Matches), applications (My Applications / Job Applied Status), downloads. NOTE: this partial intentionally does NOT include the rich profile card (photo / hire-status toggle / profile-completion bar) that candidate_dashboard.html shows above its sidebar nav -- that widget needs extra context (profile_completion %, etc.) that only the dashboard view computes. Here we show a simple ID badge instead, built straight from request.user, so this partial works unmodified on any candidate-facing page. ══════════════════════════════════════════════════════════════════ {% endcomment %}
